---
description: How to handle code change requests from the user
---

When the user asks for a code change, feature, or fix, always follow this flow:

1. **Analyze** the relevant files and understand the current state of the code.

2. **Explain the problem or goal** clearly in plain language. What is causing the issue or what needs to happen?

3. **Present the available options**, listing at least 2 approaches when possible. For each option:
   - Briefly describe how it works
   - List its pros/cons or tradeoffs
   - Mention if it requires changes to CSS, TSX, or both

4. **Give a clear recommendation** on which option you would implement and why.

5. **Wait for user confirmation** before making any changes. Ask: "¿Quieres que lo aplique?"

6. Once the user confirms, implement the chosen approach.
